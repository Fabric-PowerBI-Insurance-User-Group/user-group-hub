# FPBIUG Speaker Community

FPBIUG recruits experienced experts and emerging user group voices. Potential speakers include Microsoft Data Platform MVPs, Fabric and Power BI practitioners, Microsoft employees, Saturday Morning Learning presenters, super users, customer practitioners, and first-time speakers.

FPBIUG provides clear expectations, responsive coordination, technical checks, a structured run of show, optional publication choices, relevant promotion, and an education-first environment.
