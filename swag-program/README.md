# FPBIUG Swag and Recognition

Swag supports meaningful user group behaviors: joining, attending, returning, learning, referring peers, contributing, speaking, and volunteering.

## Eligible Activities

| Activity | Intended Outcome | Typical Recognition |
|---|---|---|
| Live attendance | Habit formation | Monthly drawing |
| Bringing a first-time attendee | Organic growth | Bonus entry |
| Meaningful Q&A or poll participation | Active engagement | Bonus entry |
| Certification-cohort completion | Learning commitment | Cohort drawing |
| Speaking or volunteering | Community sustainability | Appreciation item |

## Geographic Scope

Physical swag shipping is limited to the **United States** unless individual event rules state otherwise.

## Fairness and Privacy

Publish rules before each drawing, provide a no-purchase entry method, use a fair selection process, define organizer and repeat-winner eligibility, collect addresses privately, retain only what is required for fulfillment, and never imply Microsoft sponsorship without authorization.
