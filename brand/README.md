# FPBIUG Brand Assets

## Primary Mark

`fpbiug-logo.png` is the square conference-style badge for the **Fabric & Power BI Insurance User Group**. The mark combines Fabric and Power BI product-inspired symbols, insurance and analytics imagery, a metropolitan skyline, user group silhouettes, and the themes **Learn**, **Connect**, **Grow**, **Insights**, **Data**, and **Impact**.

## Usage Standard

- Preserve the original proportions and clear space around the badge.
- Use the alternative text: **“Fabric and Power BI Insurance User Group badge.”**
- Use the badge as a user group identity, not as evidence of sponsorship or endorsement.
- Do not recolor, stretch, crop through the border, or place the badge over visually noisy backgrounds.
- Retain a high-resolution master outside GitHub for print and event production.
