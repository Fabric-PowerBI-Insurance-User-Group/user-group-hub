# Security and Responsible Disclosure

## Never Commit

- Passwords, API keys, access tokens, private keys, or connection strings
- Tenant identifiers, private meeting links, private chat exports, or unpublished recordings
- Registration exports, attendee contact information, consent records, or swag shipping data
- Customer, employer, partner, or production data

## Safe Demonstrations

Use synthetic or fully de-identified data. Review screenshots, browser tabs, notifications, terminal history, and recordings before publication.

## Reporting

Do not open a public issue for a suspected exposure. Contact one of the co-owners privately. Public contact email: **To be determined**.
