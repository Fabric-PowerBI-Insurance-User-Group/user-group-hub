# FPBIUG Program Portfolio

## Monthly User Group Meeting

**Schedule:** Second Tuesday evening of each month at **5:45 PM Eastern Time**.  
**Purpose:** Create a predictable flagship experience that builds credibility, return attendance, and reusable knowledge.

Recommended formats include featured talks, live demos, Ask the Expert, panel discussions, hands-on workshops, and user group showcases.

## User Group Office Hours

**Status:** Coming Soon.  
Office hours will be designed as an informal peer-learning experience. Timing, facilitation model, and launch criteria will be published before the series begins.

## Certification Cohorts

**Model:** Separate time-bound series, once launched, twice weekly for two to three weeks.  
**Initial certifications:** PL-300, DP-600, and DP-700.

Cohorts should use current official learning objectives, approved practice materials, discussion, and hands-on activities. Participation does not guarantee an exam result.

## Special Experiences

Special programming can create energy without overloading the recurring calendar. Candidate formats include quarterly demo days, expert panels, product-team conversations, member showcases, and focused workshops.
