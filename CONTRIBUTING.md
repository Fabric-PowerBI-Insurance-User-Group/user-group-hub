# Contributing to FPBIUG User Group Hub

Thank you for helping the Fabric & Power BI Insurance User Group **learn, connect, contribute, and grow**.

## Contribution Paths

- Propose a session, event, resource, template, or documentation improvement.
- Correct technical inaccuracies, broken links, accessibility problems, or unclear language.
- Share reusable examples built with synthetic or fully de-identified data.
- Improve speaker, attendee, volunteer, or publishing experiences.

## Production Workflow

1. Review the repository purpose and applicable standards.
2. Open an issue for a material change or new content area.
3. Create a focused branch or fork.
4. Make the smallest coherent change that delivers the intended value.
5. Validate links, Markdown rendering, heading order, image alternatives, and file names.
6. Confirm the contribution contains no credentials, private contact details, attendee data, production data, or confidential information.
7. Submit a pull request with a clear summary, publication status, and any required approvals.
8. Address reviewer feedback before merge.

## User Group Content Guardrails

- Content is educational and technology-focused.
- Do not present legal, regulatory, compliance, audit, tax, or jurisdiction-specific guidance.
- Do not share exam dumps, recalled exam questions, or restricted certification materials.
- Use only content you have the right to publish and credit original sources.
- Avoid sales-only material. Product or employer affiliations should be disclosed when relevant.
- Prefer accessible, reusable content with explicit prerequisites and learning objectives.
