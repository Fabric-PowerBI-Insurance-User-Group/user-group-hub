# FPBIUG Volunteer Program

## Ways to Contribute

| Role | Contribution |
|---|---|
| Event host or co-host | Welcome the audience and guide the live experience |
| Speaker coordinator | Recruit, onboard, and support presenters |
| Q&A moderator | Curate questions and resource links |
| Study-group facilitator | Guide preparation and peer learning |
| Demo producer | Validate setup, files, and screen-sharing readiness |
| Accessibility reviewer | Review structure, contrast, alternatives, and captions |
| Video producer | Prepare recordings, chapters, captions, and descriptions |
| Content editor | Improve clarity, technical accuracy, and reuse |

```text
Attend → Help once → Own a task → Facilitate → Lead → Mentor
```

Volunteers should receive bounded assignments, documentation, support, and visible recognition.
