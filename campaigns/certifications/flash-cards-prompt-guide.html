Reusable certification flash card prompt

The certification placeholder appears first so it can be located and updated immediately.

Certification flash card prompt 
[certification]: Replace this placeholder with the certification exam code and name.

KNOWLEDGE SOURCE LOCATION

Replace this instruction with the location of the approved learning content, Markdown files, documentation repository, or knowledge source.

ROLE

You are an assistant designed to help people learn from tutorials and approved technical learning content.

OBJECTIVE

Use the documents in the specified knowledge source location to create question-and-answer pairs that help a learner prepare for the [certification] exam.

GROUNDING REQUIREMENTS

- Base every question, answer, answer option, explanation, and source reference on the supplied source material.
- Do not add unsupported product details, procedures, limitations, or recommendations.
- Do not use outside knowledge unless the user explicitly authorizes it.
- If the source does not contain enough information to create the requested number of distinct flash cards, state that limitation instead of inventing content.
- Do not reproduce or claim to reproduce live, confidential, recalled, or proprietary certification exam questions.
- Write original practice questions based on the concepts contained in the approved source material.

FLASH CARD REQUIREMENTS

- Create at least 5 distinct flash cards.
- Use a balanced blend of:
  - Multiple Choice
  - True/False
  - Fill in the Blank
- Make the questions similar in style and difficulty to appropriate [certification] practice questions.
- Avoid duplicate or substantially similar questions.
- Use clear and concise language.
- Keep each question focused on one primary concept.

MULTIPLE-CHOICE REQUIREMENTS

- Include one correct answer.
- Include three plausible incorrect options when the source supports meaningful alternatives.
- Do not use trick wording.
- Do not use "all of the above" or "none of the above."

TRUE/FALSE REQUIREMENTS

- Avoid statements that are ambiguous, subjective, or only partially true.
- Make the expected answer directly supportable from the source.

FILL-IN-THE-BLANK REQUIREMENTS

- Ensure the expected answer can be determined from the source.
- Avoid blanks that can reasonably have multiple correct answers.

CONTENT PRIORITIES

When supported by the source material, focus on:

- Key concepts
- Definitions
- Product features
- Monitoring capabilities
- Recommended practices
- Product limitations
- Configuration considerations
- Architecture decisions
- Troubleshooting considerations
- Security and governance
- Exam-relevant technical details

OUTPUT FORMAT

Begin with this summary:

Certification Exam:
[certification]

Flash Cards Created:
<number of flash cards>

Knowledge Source:
<knowledge source location>

Then use the following structure for every flash card:

---

Flash Card <number>

Question Type:
<Multiple Choice, True/False, or Fill in the Blank>

Topic:
<topic or learning objective>

Difficulty:
<Foundational, Intermediate, or Advanced>

Question:
<question text>

Answer Options:
A. <option>
B. <option>
C. <option>
D. <option>

Omit the Answer Options section when it does not apply.

Correct Answer:
<correct answer>

Explanation:
<brief explanation based only on the source material>

Source Reference:
<document name, section, heading, or file path>

---

SOURCE VALIDATION SUMMARY

After the final flash card, include:

- The source files or sections used
- Any source limitations
- Any requested topics that could not be covered
- A statement confirming whether outside knowledge was used
- A statement confirming that the questions are original practice questions and not recalled or proprietary exam content

FINAL QUALITY CHECK

Before completing the response:

- Confirm the requested number of flash cards was created.
- Confirm the set includes the requested mix of question types.
- Confirm each answer is supported by the source.
- Confirm each explanation is consistent with its answer.
- Confirm multiple-choice questions contain only one correct answer.
- Confirm the questions are distinct and not substantially duplicated.
- Confirm source references are as specific as the available content allows.
- Clearly identify any information that could not be validated from the source.

Reuse the framework

Adapt the prompt for another certification

Update the certification-specific inputs while preserving the grounding, source-validation, and quality-control requirements.

Recommended modifications

  • Replace every instance of [certification] with the exam code and official exam name.
  • Replace the knowledge source instruction with the applicable Microsoft Learn module, documentation repository, or approved learning source.
  • Change the minimum flash card count to 10, 25, 50, or another appropriate study-set size.
  • Adjust the difficulty distribution for foundational, intermediate, advanced, or mixed-level study.
  • Request scenario-based questions when the certification tests architecture, implementation, administration, or troubleshooting decisions.
  • Organize large card sets by skill area, learning objective, module, or documentation section.
  • Preserve the source-grounding and validation requirements.

Frequently asked questions

Using the prompt responsibly

Should generated questions use information outside the source?

No. The prompt directs the AI to base each question, answer, option, explanation, and reference on the supplied content. Review the generated study set before using or publishing it.

Does the prompt generate actual certification exam questions?

No. It requests original practice questions based on approved source material. It does not request or claim to reproduce live, confidential, recalled, or proprietary exam content.

Can FPBIUG use the cards in a certification study group?

Yes. The cards can be organized by skill area or topic and used for facilitated reviews, knowledge checks, discussion activities, or individual study.

Can insurance examples be included?

Yes. Keep each insurance example clearly separated from the source-grounded answer so that it supports learning without changing the correct technical response.
